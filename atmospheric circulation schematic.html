0考纲定位与学习目标

必考核心高考高频 ▸

大气环流是自然地理环境中最核心的“骨架”之一。高考对本专题的考查很少孤立设问，通常把它放进“气候成因—天气变化—区域旱涝—海气相互作用”的综合链条中，要求由气压带、风带的位置与性质，推导气温、降水、天气及农业生态后果。

考纲定位：大气环流是高考高频考点，常与气候类型、天气系统、海气相互作用、区域旱涝结合考查；既可单独考原理，也可作为综合题的前置条件。

学习目标

  1. 理解热力环流的完整因果链，会用等压面判断高低压。
  2. 掌握三圈环流的形成条件、三个环流圈与七个气压带、六个风带。
  3. 会判读任意半球、任意季节的风向与干湿属性。
  4. 能解释季风环流、副高雨带、非地带性特殊现象与局地环流修正。
  5. 能完成气候类型判读、特点描述与成因分析。
  6. 能写出“环流—水汽—抬升—降水—影响”的综合题因果链。

1大气环流：概念、尺度与意义

必考核心概念基础 ▸
定义：大气环流是地球上各种规模大气运动的综合表现，包括行星风系、季风环流和地方性环流。

三个尺度

大气环流的三个尺度及其高考呈现方式
尺度主要系统空间与时间特征高考呈现方式
行星尺度三圈环流、气压带风带、副热带高压、急流全球或半球范围，常年稳定存在作为气候成因的背景条件，要求判断风带性质与季节移动
海陆尺度季风环流、大气活动中心大陆与大洋之间，随季节反向东亚、南亚季风成因与强弱比较，我国雨带与旱涝
局地尺度海陆风、山谷风、城市热岛、湖陆风、冰川风几千米到几十千米，昼夜变化明显解释某地昼夜风向反转、背景环流被局地环流修正

根本能源与形成基础

根本能源是太阳辐射。高低纬度获得的太阳辐射量不同，形成高低纬之间的热量差额；赤道多余热量向北、向南输送，极地亏损热量则通过大气和洋流补充。地转偏向力使气流发生偏转，海陆热力差异使纬向气压带被切断，地形与洋流再作局部修正。

作用

  • 促进高低纬之间、海陆之间的热量与水汽交换。
  • 调整全球水热分布，缓解高低纬温差。
  • 是天气变化和气候形成的基础背景，也是水循环的重要动力。
  • 通过风带影响洋流、航海、风力发电与污染物扩散。
逻辑主线：太阳辐射差异 → 高低纬受热不均 → 大气运动 → 三圈环流 → 气压带风带 → 叠加季节移动、海陆差异、地形洋流 → 气候类型输出。

2热力环流原理与局地实例

必考核心上升下沉高考高频 ▸

因果链

地面冷热不均→ 空气垂直运动（热上升、冷下沉）→ 同一水平面产生气压差→ 空气水平运动（风）

判读铁律

  • 近地面：热处为低压，冷处为高压。
  • 高空：气压性质与近地面相反，热处高空为高压，冷处高空为低压。
  • 等压面凸向高处为高压，凸向低处为低压；近地面与高空的凸向相反。
  • 水平方向上，风始终由高压吹向低压；垂直方向上，上升处近地面低压、下沉处近地面高压。

3三圈环流：从单圈到三圈

必考核心上升下沉高考高频 ▸

单圈环流：一个理想模型

假设地表性质均一、地球不自转，赤道受热上升、极地冷却下沉，高空由赤道流向极地、近地面由极地流向赤道，形成南北向闭合的热力环流。单圈环流只解释了高低纬温差，没有考虑地转偏向力，因此与真实情况不符。

三圈环流的形成条件

  • 前提：地表性质均一，太阳直射赤道。
  • 根本因素：高低纬受热不均。
  • 重要因素：地转偏向力，使南北向气流发生偏转，单圈环流被“拆”成三圈。

哈德莱环流（0°—30°）

热力驱动的正环流。赤道空气受热上升，高空向高纬流动并偏转，在30°附近堆积下沉，近地面返回赤道形成信风。

费雷尔环流（30°—60°）

动力维持的逆环流。副高近地面气流流向高纬形成西风，与极地东风在60°附近交汇抬升，高空返回副高。

极地环流（60°—90°）

热力驱动的正环流。极地冷却下沉，近地面流向低纬形成极地东风，在60°附近被迫抬升。

极锋与副极地低压带

60°附近，暖而轻的盛行西风与冷而重的极地东风相遇，形成极锋。暖空气沿锋面被迫抬升，近地面气压降低，形成副极地低压带。因此副极地低压带的本质是动力成因的锋面抬升，不是单纯受热上升。

核心判断：副热带高压带、副极地低压带为动力成因；赤道低压带、极地高压带为热力成因。这是选择题和综合题的高频陷阱。
记忆口诀：赤道升、三十沉、六十抬、极地沉。

4七个气压带与六个风带

必考核心多雨干燥高考高频 ▸

七个气压带

赤道低压带、北副热带高压带、南副热带高压带、北副极地低压带、南副极地低压带、北极地高压带、南极地高压带。

六个风带

北信风带、南信风带、北盛行西风带、南盛行西风带、北极地东风带、南极地东风带。

北半球风向

信风：东北风；盛行西风：西南风；极地东风：东北风。

南半球风向

信风：东南风；盛行西风：西北风；极地东风：东南风。

气压带与风带的降水属性

  • 低压带气流上升，水汽冷却凝结，多雨；高压带气流下沉，增温不易凝结，干燥。
  • 西风由较低纬吹向较高纬，温暖湿润；若来自海洋且遇迎风坡，降水丰富，背风侧则干旱。
  • 信风一般由较高纬吹向较低纬，气温升高、不易凝结，通常干燥；但大陆东岸迎风坡、叠加暖流时可多雨。
  • 极地东风寒冷干燥，降水少。
干湿判读原则：不能只看名称，要看气流方向、水汽来源、地形迎风或背风、洋流暖或寒，四者联判。

5气压带风带的季节移动

必考核心交替控制易错 ▸

移动原因

太阳直射点在南北回归线之间做回归运动，全球热量分布随季节变化，气压带和风带随之整体移动。

移动规律

  • 北半球夏季，太阳直射点北移，气压带风带北移；北半球冬季南移。
  • 南半球季节相反：1月南移，7月北移。
  • 移动幅度约为 5°—10°，明显小于太阳直射点 23.5° 的移动幅度，因为下垫面热力惯性、海陆分布会削弱移动。

后果：交替控制

同一地区不同季节受不同气压带或风带控制，形成干湿季交替。典型接口是热带草原气候（赤道低压带与信风带交替）和地中海气候（副热带高压带与西风带交替）。

气压带风带季节移动的典型表现
时间太阳直射点气压带风带位置典型现象
1月南半球整体南移地中海沿岸受西风带控制，温和多雨；南亚受东北季风控制

6海陆分布与大气活动中心

必考核心高考高频切断 ▸

北半球陆地面积大，纬向气压带被海陆热力差异切断，形成随季节变化的大气活动中心；南半球海洋占绝对优势，气压带保存较完整。

形成逻辑

  • 陆地比热容小，升温快、降温也快；海洋比热容大，温度变化平缓。
  • 夏季大陆强烈增温，近地面形成热低压，把副热带高压带“顶掉”；冬季大陆强烈冷却，形成冷高压，把副极地低压带“顶掉”。
  • 海洋上的活动中心相对稳定，具有半永久性。

7季风环流

必考核心高考高频多雨干燥 ▸
季风定义：大范围地区盛行风向随季节显著改变的大气环流。

东亚季风

夏季东南风，温暖湿润；冬季西北风，寒冷干燥。主要成因是海陆热力性质差异；冬季风强于夏季风。典型区域为我国东部、朝鲜半岛、日本。

南亚季风

夏季西南风，高温多雨；冬季东北风，温暖干燥。成因是海陆热力差异叠加气压带风带季节移动；夏季风强于冬季风。典型区域为印度半岛、中南半岛。

南亚夏季西南风的双重成因

南半球东南信风随太阳直射点北移，越过赤道后受北半球地转偏向力作用向右偏转，形成西南风；同时，亚欧大陆夏季热低压与印度洋高压之间的海陆热力差异进一步加强了西南风。答题时必须写出“东南信风越赤道右偏”，不能只写海陆热力差异。

东亚季风最典型的原因

东亚背靠世界上最大的大陆——亚欧大陆，面向世界上最大的大洋——太平洋，海陆热力差异的振幅最大，因此季风最典型、冬夏季风方向最稳定。

越赤道偏转拓展

  • 澳大利亚西北部夏季的西北风，是北半球东北季风南移越过赤道后受南半球地转偏向力左偏形成。
  • 非洲几内亚湾沿岸夏季也受越赤道偏转气流影响，形成湿润的西南风。

8副热带高压与我国雨带

旱涝逻辑

  • 副高控制区盛行下沉气流，天空晴朗、气温高、降水少，易形成伏旱。
  • 副高西北侧是暖湿气流辐合上升区，多对流雨和锋面雨，易发生洪涝。
  • 副高偏强、位置偏北，雨带北移快，可能出现“南旱北涝”；副高偏弱、位置偏南，雨带滞留南方，可能出现“南涝北旱”。
  • 判断旱涝时必须区分“控制区”和“西北侧边缘”，不能笼统写“受副高影响”。
高考设问落点：副高偏强或偏弱、北跳偏早或偏晚，会导致某地旱还是涝；答题要落到副高位置、气流方向、雨带位置三个变量。

9大气环流对降水的控制

必考核心综合题上升下沉答题模板 ▸

降水的三个基本条件

  1. 充足的水汽供应。
  2. 气流上升、冷却降温，水汽达到过饱和并凝结。
  3. 有足够的凝结核。

环流对降水的控制逻辑

  • 低压带气流上升，多雨；高压带气流下沉，少雨。
  • 西风来自海洋时温暖湿润，遇迎风坡多雨；背风侧雨影区干旱。
  • 信风在大陆西岸和内陆一般干燥，但在大陆东岸迎风坡叠加暖流时可多雨。
  • 夏季风来自海洋，湿润多雨；冬季风来自陆地，干燥少雨。
  • 同一环流背景下，地形与洋流会改变降水结果，因此必须综合判断。
降水成因答题模板：
大气环流（气压带、风带、季风）+ 地形（迎风坡或背风坡）+ 洋流（暖流增湿、寒流减湿）+ 海陆位置→ 水汽来源→ 抬升机制→ 降水结果

不能只写“受西风影响”，必须落实到水汽从哪里来、靠什么抬升、最终降水多还是少。

常见抬升机制

对流抬升

地面受热强烈，空气上升冷却，多形成对流雨，常见于赤道低压带和夏季午后。

锋面抬升

冷暖空气交汇，暖空气沿锋面爬升，多形成锋面雨，常见于副极地低压带和季风区。

地形抬升

湿润气流遇山地被迫抬升，迎风坡多雨，背风坡形成雨影。

气旋辐合抬升

低压中心四周气流辐合上升，多阴雨天气，台风和温带气旋均属此类。

综合题提醒：分析某地降水成因时，先定位其所处气压带或风带，再判断气流上升或下沉，最后叠加地形、洋流和海陆位置，形成完整因果链。

10大气环流的输出：气候类型全表

必考核心高考高频判读模板 ▸

气候是大气环流长期作用的结果。纬度决定热量基础，大气环流决定水汽输送与升降运动，海陆位置、洋流、地形作进一步修正，最终形成不同类型的气候。

气候形成的五大因子

纬度

决定太阳辐射和热量带，是气候差异的基础。

大气环流

决定水汽来源、气流升降与季节变化。

海陆位置

影响海洋性、大陆性程度和季风强弱。

洋流

暖流增温增湿，寒流降温减湿。

地形

海拔影响气温，坡向影响降水，形成垂直差异。

下垫面性质

植被、冰雪、湖泊等改变局部热量与水分条件。

气候判读三步

  1. 以温定带：看最冷月均温判断热量带。最冷月大于15℃为热带；0—15℃为亚热带或温带海洋性；小于0℃为温带；最热月小于10℃为亚寒带或寒带。
  2. 以水定型：看年降水总量与季节分配。全年多雨、夏雨集中、冬雨为主、全年少雨分别对应不同气候。
  3. 海陆位置验证：结合大陆东岸、西岸、内部，判断季风、西风、大陆性等成因是否吻合。

三种成因模型

单一气压带或风带控制

终年受赤道低压带控制形成热带雨林；终年受西风带控制形成温带海洋性；终年受副高或信风控制形成热带沙漠。

交替控制

赤道低压带与信风带交替形成热带草原；副热带高压带与西风带交替形成地中海气候。

季风控制

海陆热力差异导致冬夏季风交替，形成热带季风、亚热带季风和温带季风气候。

12局地环流与背景环流修正

高考高频拓展风向反转 ▸

五类局地环流

  • 海陆风与湖陆风：水陆比热容差异导致昼夜风向反转。
  • 山谷风：白天谷风沿坡上升，夜晚山风沿坡下沉。
  • 城市热岛环流：城市热低压，近地面风由郊区吹向城市。
  • 绿洲—沙漠风：绿洲与沙漠热力差异形成局地闭合环流。
  • 冰川风：冰川表面强烈冷却，冷空气沿冰面下沉，与山谷风同属热力环流的局地表现。

核心逻辑

大尺度背景环流提供“基态”，局地下垫面热力差异在其上叠加“修正”。当局地热力差异足够强时，近地面可能出现与背景环流方向相反的风。

高考设问落点：解释某时某地为何出现与背景环流相反的风，答题要落到局地下垫面热力差异的强度、昼夜变化和地形条件。

13沃克环流与 ENSO

高考高频拓展上升下沉 ▸

正常年份的沃克环流

赤道太平洋西侧（印尼、澳大利亚附近）海水暖，东侧（南美西岸）海水冷。西侧空气受热上升，东侧空气下沉；低层气流由东向西，高层由西向东，形成东西向闭合热力环流，即沃克环流。

厄尔尼诺

  • 赤道东太平洋海水异常增温，东西温差减小。
  • 沃克环流减弱，甚至反向。
  • 南美西岸降水异常增多，易发生洪涝；澳大利亚、印度尼西亚一带降水减少，易发生干旱。

拉尼娜

  • 赤道东太平洋海水异常偏冷，东西温差增大。
  • 沃克环流加强，方向不变。
  • 澳大利亚、印度尼西亚降水偏多；南美西岸降水偏少。

高中要求：理解沃克环流作为大气环流异常的背景即可，不深究海洋动力学。高考常以“海气相互作用 + 环流异常 + 区域气候响应”的组合出现。

14判读方法、答题模板与高考考法

必考核心高考高频综合题模板 ▸

判读方法

  • 判读气压带风带示意图：先看纬度位置，再看气流垂直方向，最后看风向偏转。
  • 判读风向：近地面风由高压吹向低压，北半球右偏、南半球左偏；高空风与等压线平行。
  • 判读干湿：上升或下沉 + 水汽来源 + 地形迎风或背风 + 洋流暖或寒，四者联判。
  • 判读季节：看大陆气压性质，大陆低压为夏季，大陆高压为冬季；再看气压带风带整体位置。

综合题模板

成因类

按“太阳辐射—大气环流—海陆位置—地形—洋流”逐项排查，先定热量带，再定水汽与升降，最后写局部修正。

影响类

按“热量—水分—天气—气候—农业与生态”展开，注意区分有利影响与不利影响。

高考新情境

新高考往往不直接问“这是什么风”，而是给出气压、气温、降水或等压线分布，要求反推气流结构，并补出垂直运动和天气效应。复习时把每个风带、气压带都翻译成“上升还是下沉 → 多雨还是少雨 → 对区域意味着什么”。

大气环流综合题答题链

审题定位→ 判断所在气压带或风带→ 判断气流上升或下沉→ 判断水汽来源→ 叠加地形与洋流→ 得出气温降水特征→ 落到农业生态影响
表述模板：该地地处某纬度、受某气压带或风带控制，气流以上升或下沉为主，水汽主要来自某海洋或内陆，叠加迎风坡与暖流或背风坡与寒流，因此形成某气候，具有某气温与降水特征，进而影响当地农业类型与生态景观。
高考提醒：综合题中“成因”和“影响”要分开写；成因写环流与下垫面，影响写对气温、降水、农业、生态、灾害的具体作用，避免把成因和影响混在一句话里。

一句话总纲

太阳辐射造成高低纬受热不均，地转偏向力把单圈环流拆成三圈，形成七气压带六风带；直射点移动使气压带风带季节移动，海陆差异切断气压带并形成季风；副高北跳决定我国雨带，地形洋流造成非地带性，局地下垫面修正背景环流，海气相互作用引发沃克环流异常，最终输出复杂多样的气候类型。
